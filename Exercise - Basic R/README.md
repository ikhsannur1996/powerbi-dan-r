# 📝 Exercise — Basic R

> Kumpulan **10 latihan** pendamping Volume 0 (Basic R, Data Manipulation & Data Visualization). Kerjakan berurutan — tiap latihan membangun di atas latihan sebelumnya.
>
> Dataset: `../quality_inspection.csv`
> Prasyarat: R + RStudio terpasang, package `dplyr`, `lubridate`, `ggplot2`, `scales` terinstal.

---

## Cara pakai folder ini

1. Buka RStudio → **File ▸ New Project** (atau pakai project Volume 0).
2. Buka file latihan (mis. `latihan-01-objek-dasar.md`).
3. Kerjakan semua **Soal** di script R kosong (`File ▸ New File ▸ R Script`) — jalankan baris per baris.
4. Cek hasil dengan bagian **Target** dan **Cek pemahaman**.
5. Baru setelah selesai, bandingkan dengan **Kunci jawaban** di bagian bawah tiap file.

> Aturan main: jangan lihat kunci sebelum mencoba minimal 15 menit. Error adalah bagian dari latihan — baca pesannya, perbaiki, jalankan ulang.
